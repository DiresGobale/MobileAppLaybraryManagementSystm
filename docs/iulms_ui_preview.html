How It Works
Borrowing in 4 simple steps
1
🔍 Browse the Catalog
Search by title, author, ISBN, or category.
2
📖 Find Your Book
Locate the shelf using the location code (e.g. A-12).
3
📚 Borrow at the Counter
Librarian issues the loan and stamps your slip.
4
↩ Return on Time
Return on/before due date to avoid blocks.
